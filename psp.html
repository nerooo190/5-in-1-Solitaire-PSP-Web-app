5 in 1 Solitaire — PSP original

This runs the original game code in a PSP emulator (PPSSPP, WebAssembly) inside your browser — a 1:1 copy, not a remake. Choose your own game file; it is read locally and never uploaded.

Drop your .iso / .cso here or click to choose No file selected
Default keys: arrows = D-pad · X = ✕ · Z = ○ · S = □ · A = △ · Enter = Start · V = Select (rebindable in the emulator menu). The emulator currently renders in software inside the browser, so higher resolutions get slow quickly: start with the native resolution and give the first picture up to a minute.
