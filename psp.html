5 in 1 Solitaire — PSP original

This runs the original game code in a PSP emulator (PPSSPP, WebAssembly) inside your browser — a 1:1 copy, not a remake. Choose your own game file; it is read locally and never uploaded.

Drop your .iso / .cso here or click to choose No file selected
Default keys: arrows = D-pad · X = ✕ · Z = ○ · S = □ · A = △ · Enter = Start · V = Select (rebindable in the emulator menu). The original game runs at the PSP's native 60 fps; the resolution setting only changes how sharp it is drawn. Looking for the remake with 4K / up to 120 fps rendering? Open the web remake.
